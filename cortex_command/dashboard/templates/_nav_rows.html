{# The list rows — READY, BLOCKED, and the tail panels. One macro, three callers, because the three lists differ in exactly one way (blocked rows name what holds them) and it is worth being able to see that they do not differ in any others. A reader learns one row grammar. FOUR COLUMNS. The board used to print seven. Two of the three that went were blank most of the time: "why it sits here" was empty on 54 of 78 rows and the rank was empty on 46 of 51 startable ones, and between them they took the width that wrapped half the titles onto a second line. The band letter went because the section a row is in already says what the letter said. What survives of the band is a single glyph in the points cell, present on three bands out of eleven — a keyholder, a resumable, a lapsed hold. Sparse by construction, so it reads as an exception rather than as a column. The rows are a real . Not a styling preference: the title column is `table-layout` free and carries the full untruncated title, and the points column is tabular-nums, so a reader can compare seventy rows down a column that a flex run could never hold still. A row's position is never computed from a character advance — the fonts are not bundled and Georgia is what renders. Exactly one per cell that has one. The blocker links are siblings of the id link, never descendants: nested anchors are invalid HTML and they shattered 41% of one prototype's board. Every row is `.js-ticket` carrying its own `data-t-*` payload, so the hover card paints from values this render already computed and the click opens the modal. The href stays real and stays first, so cmd-click, middle-click, "open in new tab" and a browser with no JS all still reach the page. #} {# The hover payload, from whichever hoverable dict the caller has. A list row, a frame node and an epic child tile all answer to the SAME keys — see ``view._hover``, which is merged flat into each of them. The first cut of this nested the payload under a ``preview`` key on nodes and tiles but not on rows, so this macro read four of six attributes as Undefined on every node in every frame and rendered them as empty strings, with no error anywhere.
