{# The edit form for one governing document. Included by doc_page.html in edit mode; reads ``doc``, ``edit_view`` (path, text, sha), ``conflict`` (the SaveResult of a refused save, or none), ``save_error`` (a refusal message, or none) and ``repo_query``. The hidden ``sha`` is the content hash of the bytes the textarea was filled from. The save verb re-hashes the disk file and refuses with 409 when they differ, which is what makes this a lock rather than a race: an edit from another session between open and save can never be overwritten silently. On a conflict the operator's text stays in the textarea, the disk version is shown beneath it, and the hidden field carries the FRESH hash — so a second save is an informed overwrite of exactly the version they were shown. Writes the file and nothing else: no add, no commit, no stash. The change appears in ``git status`` and whichever session commits next carries it. #}
