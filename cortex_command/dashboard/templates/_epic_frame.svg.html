Consumes ``layout_epic``'s geometry verbatim — every x, y, width, height and path `d` below was computed in Python and no coordinate is derived here. **Nothing measures text.** That rule stands; what changed is which side of it the titles sit on. A node is a ```` the server sized and placed, holding ordinary HTML: CSS wraps and clamps the title inside a box whose dimensions were already decided. The fonts are still not bundled and Georgia is still what renders — that is now harmless, because a wider font wraps sooner instead of overflowing a box sized to a guessed advance. The collisions in three of the five prototypes came from estimating glyph widths, which nothing here does. Because the box carries the title, the roster table that used to repeat every node underneath the diagram is gone. It was the same four columns the boxes and the hover card now carry between them, at roughly the height of the frame it annotated. The anchor is HTML and its text content is its accessible name, so there is no ```` child: browsers render that as an OS tooltip, which arrived grey and unstyled next to the hover card. The svg is ``role="group"`` rather than ``role="img"`` — an image role would hide the anchors inside it, and they are now the only way through to the tickets. The arrowhead marker id is namespaced per epic.
