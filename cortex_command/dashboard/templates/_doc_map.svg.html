{# The Docs view's shared macros: the document map and the ADR status badge. ``map_svg`` draws a ``docs.model.MapLayout`` verbatim, the way ``_epic_frame.svg.html`` draws an epic frame. Every x, y, width, height and path ``d`` was computed in ``docs.layout``; nothing here measures text or derives a coordinate. The same macro draws both the constitution ladder on ``/docs`` and the neighbourhood strip on ``/docs/{path}`` — the layout decides the shape, the template only knows the grammar. A node is a ```` of the size the layout gave it (a doc box or a smaller decision chip) holding an ordinary anchor; CSS wraps and clamps the title inside a box whose dimensions were already decided. The href stays real and stays first: a middle-click, a cmd-click, keyboard Enter and a browser with no JS all reach the doc. The ``data-d-*`` attributes feed the hover card without a fetch — every value here was computed for this map already. ``data-links`` names the nodes the map lights when this one is hovered, which is how a citation that is not a line is still visible. Three arrowhead markers per map — one per stroke colour — namespaced by the layout's ``marker_id``. A shared id makes every map after the first depend on the first staying in the DOM, and the ladder is swapped in place by the ``more`` links. The svg is ``role="group"`` rather than ``role="img"``: an image role would hide the anchors inside it, and they are the only way through to the docs. #} {% from "patterns/badge.html" import badge %} {# ADR status → badge class, picked by RENDERED result under carbon (see DESIGN.md: the class names do not name the hue). accepted paints blue and solid, proposed paints ochre, superseded/deprecated paint faint.
