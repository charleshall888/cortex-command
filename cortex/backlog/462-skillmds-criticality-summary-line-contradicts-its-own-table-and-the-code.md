## Why

Found 2026-08-06 while researching #452. `skills/build/SKILL.md:80` reads:

> Criticality decides whether Review runs; tier decides how deep it reads.

That is false. The executable rule is `criticality in {high, critical} OR tier == complex` (`cortex_command/lifecycle/implement_transition.py:175`) — **tier also decides whether Review runs**, via the `or tier == "complex"` clause. A `complex` + `medium` feature is routed to Review by tier alone.

The gate table **four lines above the sentence** already states this correctly: the `low` and `medium` rows both read *"tier-based (skip below complex)"*. So the file contradicts itself within a single section, and the summary line is the half that is wrong.

The irony is load-bearing: `c6528012` was authored specifically to fix a prose/code disagreement in this area — its `size-pin.txt` `# raised:` note (lifecycle-id=449) says *"review.md must state which tier each stage runs at, because its opening line claimed complex-tier-only while the SKILL.md gate table forced the phase at high criticality — the two disagreed and nothing resolved them"* — and it shipped the mirror-image contradiction.

**Observed cost, not hypothetical:** this sentence was quoted as ground truth in #452's ticket body ("`c6528012` already split part of the predicate: criticality decides *whether* Review runs, tier decides *how deep*") and became the stated premise of one of that ticket's four candidate routes. The research had to refute it from source before the route could be evaluated.

## Role

Make the summary line agree with the table above it and the verb beneath it.

## Integration

`skills/build/SKILL.md:80`, immediately below the criticality gate table at `:73-78`. What survives of the intended claim is narrower and true: **Stage 2 of Review is complex-only** — a depth reduction inside a phase that still runs. Nothing about *whether* the phase runs is criticality-only.

## Edges

- The table (`:73-78`) is correct — do not "fix" it to match the sentence.
- `skills/build/references/review.md:3,19` states the same split and must stay consistent with whatever wording lands.
- `skills/build/references/size-pin.txt` is at zero headroom (57964/57964) and already carries two `# raised:` exceptions; a same-size-or-smaller edit avoids a third.
- The canonical source is `skills/build/SKILL.md`; the `plugins/cortex-core/` mirror is regenerated by `.githooks/pre-commit` Phase 3 — never edit it by hand.
