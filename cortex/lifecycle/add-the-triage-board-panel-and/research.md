## Codebase: Dashboard Render Chain

**The six-seam panel recipe.** parser → `DashboardState` field → `@app.get("/partials/<name>")` (`app.py:319-429`) → panel template (a *fragment*: no `<section>` wrapper) → `<section hx-get hx-trigger hx-swap="morph">` in `base.html:2149-2214` → append to `PARTIAL_ROUTES` (`cortex_command/dashboard/tests/test_routes_smoke.py:40-51`).

**Two traps.** (a) The `§ NN` label is emitted **twice** — placeholder in `base.html` (e.g. `:2154`) and re-emitted as the partial's first line (e.g. `session_panel.html:3`) — because `hx-swap="morph"` replaces the section's entire inner content on first load; omit the second and the label vanishes. Exception: `pipeline_panel.html` carries `§ 09` only internally, because it has no placeholder. (b) `pipeline_panel.html` is server-`{% include %}`d at `base.html:2201-2203` with no `hx-get`/`hx-trigger` — the only non-refreshing section. Copying it yields a panel that never updates.

**Section numbering is manual and contiguous**, `§01`–`§10` all allocated (`§10` = backlog panel, `base.html:2206`). Placing the board adjacent to the backlog panel means renumbering and touching two files per displaced section; appending as `§11`/`§12` avoids that but puts the board at the bottom. `session_detail.html`/`sessions_list.html` run an independent per-page `§` namespace — no collision, but the per-page scheme is documented nowhere.

**Cadence.** Eight sections poll at `5s`, `activity-stream` at `3s`; only `metrics-baseline` and `backlog-panel` use `every 30s`, both paired with a `refresh · 30s` string in the template's own `stream-line`. 30s is the precedented cadence for corpus-scan panels.

**Badge layer.** `patterns/badge.html:1` — `badge(status=None, css_class=None, label=None)`. Two calling conventions coexist: `badge(status=X)` routes through `_BADGE_CLASS_MAP`/`_STATUS_ICON_MAP` (`app.py:82-106`, keyed to the **feature/run-outcome** vocabulary) and is used at only three genuinely-feature-status sites; `badge(css_class=…, label=…)` bypasses the shared maps and is the majority pattern. **The collision is sharper than a shared name:** `backlog_panel.html:2-17` already carries a template-local backlog-status vocabulary in which `blocked` → `var(--c-state-failed)` (red), while `blocked` has **no key at all** in `_BADGE_CLASS_MAP` and would fall through to `badge-gray` (`app.py:180`). A board calling `badge(status=item.status)` would render blocked tickets gray, contradicting the red the aggregate bar already uses for the same word. `deferred` coinciding on amber across both maps is luck, not contract. **Established safe pattern:** template-local status→class dict + `badge(css_class=…, label=raw_status)`, never `badge(status=…)` for backlog statuses. Available classes (`base.html:642-680`): `badge-{green,blue,red,amber,gray,purple}`.

**Templates to model on.** `backlog_panel.html:1-65` — stat-row/stack-bar with a three-way state split (non-local backend / populated / empty). `feature_cards.html:50-101` — `<details class="feature-block" id="feature-{{ slug }}">` / `<summary>` disclosure rows, **no `<a href>` on the row itself**. `session_panel.html:27-112` — `.session-grid`/`.session-cell` (label + big numeral + qualifier), an existing "several labelled numbers in a row" layout the strip can reuse with no new CSS. Two empty-state idioms coexist: `alerts_banner.html` renders nothing and `base.html:541`'s `section#alerts-banner:empty { display: none; }` collapses the chrome; `escalations_panel.html:41-43` always prints a line. Pick deliberately.

**The dead-link defect is live.** `feature_cards.html:226-228` renders `href="#"` placeholders for spec/plan/backlog — literally what epic #410's Why cites. Board rows must therefore be `<details>`/`<summary>` or plain list items, never an anchor pointing nowhere.

**Free state persistence.** `base.html:2219-2257` persists any `<details id="...">` open/closed state across morph swaps and reloads via `sessionStorage`, keyed on element id. Board rows with stable ids (`id="ticket-{{ id }}"`) inherit expand-state across the 30s poll with no new JS.

**Template resolution.** `app.py:58-76` resolves via `importlib.resources.files("cortex_command.dashboard") / "templates"`. Never add `__init__.py` under `templates/` — namespace-package extraction breaks live references. New panels are flat `.html` files, no registration.

**`DESIGN.md` is partly stale.** Its hex table (`:70-81`) predates the parchment/carbon dual-theme `@theme` block (`base.html:14-238`, switched by `data-stain`); treat `base.html` as the token source of truth. ## Web & Documentation Research

**Blocked is a flag, not a status.** Jira's Flagged field is the direct prior art: flagging does not change status, because "having a single status removes the nuance — is an item blocked during product shaping, or in testing?" (https://community.atlassian.com/t5/Jira-Software-articles/Why-flagging-Jira-issues-is-so-cool/ba-p/1872469). Collapsing blocked into the status enum is the most-cited anti-pattern in this space. The repo already matches structurally: `normalize_status` rewrites legacy `status: blocked` → `backlog`, so blocked-ness derives from `blocked_by` resolution.

**Badge vs label ownership.** GitLab Pajamas draws the line on provenance — "if the metadata is created and applied by a user, or customizable, use a label instead" — which maps onto `deferred_status` (system-derived) vs `deferred_tag` (user-applied), independently justifying R12's two-flag split. GOV.UK's Tag component: use adjectives not verbs, and tags "should not be made interactive by making it into a link or button" (https://design-system.service.gov.uk/components/tag/) — a second, independent argument for non-link rows.

**Accessibility.** Roselli's grid anti-pattern (http://adrianroselli.com/2020/07/aria-grid-as-an-anti-pattern.html): grid semantics reach screen-reader users only, arrow-key navigation breaks under responsive reflow, and the pattern demands custom focus JS. Recommended alternative is exactly the planned shape — semantic lists, heading structure, and disclosure widgets for large collapsible content. W3C APG concurs: Table for static tabular structure, Grid only for interactive widgets (https://www.w3.org/WAI/ARIA/apg/patterns/table/); Disclosure is the documented collapse pattern (https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/).

**Idiomorph guarantees less than assumed.** Its README documents focus/selection and active-input-value preservation via id-set matching, but **not** scroll position and **not** `<details>` open state (https://github.com/bigskysoftware/idiomorph). Community workarounds pair `hx-preserve` with `hx-swap-oob` (https://github.com/bigskysoftware/htmx/discussions/1004); scroll loss on polled swaps is reported open (https://github.com/bigskysoftware/htmx/issues/2953). In this codebase the gap is already covered by the sessionStorage restore at `base.html:2219-2257`, not by morph. htmx #1671 reports load-polling plus morph firing once then stopping — but ten shipped panels use exactly `hx-trigger="load, every Ns"` + `hx-swap="morph"` today, so the pinned version is unaffected; recorded as verified-by-existing-use.

**Strip typography.** Semantic colors carry severity connotations users read as urgency regardless of intent (SAP Fiori: "only use a semantic color if you need to convey the meaning defined for that color"); Lippert's traffic-light critique argues for plain accurate text over borrowed signal vocabularies (https://ericlippert.com/2014/11/11/traffic-light-ux/). For a strip explicitly framed as neutral, that means **no badges, no color, no icons** — plain running counts.

**Grouping thresholds.** No vendor or NN/g source gives a numeric board-vs-list cutover. Linear and GitHub Projects both solve the sparse case by **collapsing or hiding empty groups** rather than switching layout mode (https://linear.app/docs/board-layout). The only quantified anchor is Miller's-Law chunking (~5–9), and it comes from secondary UX sources, not NN/g — flagged rather than presented as authority.

## Tradeoffs & Alternatives

1. **Board IA — presence-based grouping, no threshold.** One section per epic present in the feed's `epics` map; everything that is nobody's child falls into one flat list — the partition `triage.py:141-183` already performs. This removes the magic number entirely, answers "what about unparented items" by construction, and degrades continuously across 0 → 5 → 10 → 58. A count threshold would instead introduce a discontinuity where the page changes shape without the data changing meaning. **Cheaply reversible** — a rendering choice over already-computed input.
2. **Three orthogonal signals.** One status badge from a **template-local** status→class dict (mirroring `backlog_panel.html:2-17`, never `_BADGE_CLASS_MAP`); tag-deferral as a non-badge text flag under a distinct class prefix so it can never inherit amber-badge styling; blocked as its own local-map badge plus a plain-text reason from `blocked_why`. Three full badges per row is rejected as noise at 58 rows. The local-dict route is the only option that *structurally* cannot re-collide.
3. **Strip — three terms, own section after the board**, `.stream-line` styling (the existing idiom for meta information, `backlog_panel.html:26-29`), never alert/warning classes and never the `role="alert"` banner region, which would misrepresent neutral counts as urgent.
4. **Scan cadence — inside `_poll_slow` at 30s, own bulkhead, outside the backend gate.** ~7ms added to a block going to ~32ms: ~0.1% duty cycle. Compute-once-at-startup lets the corpus drift silently; per-request is unnecessary for a single-operator loopback tool; a fifth task is requirement-barred.
5. **Do not build `patterns/data-table.html`.** One real call site cannot tell you which parts vary. The repo's existing macros read as extractions after multiple uses. Extracting later from working template code is the cheap direction; committing to a speculative shape now is the expensive one.
6. **Two independent polled partials**, matching the 1:1 route-per-panel grain of all ten existing partials and keeping fixtures decoupled (a board test needs no lifecycle dirs). "One panel plus a static strip" reproduces the `pipeline_panel.html` trap.
7. **Never self-hide.** No existing panel does; all render the section shell and swap inner content for a one-line `<p class="empty-state">`. The Edge "renders honestly at both extremes … no padded chrome" means don't pad, not hide. **`backlog_snapshot is None` must render a distinct "loading/never-polled" state** from a populated-but-empty snapshot — R2 preserves that distinction deliberately, and collapsing them would present "never scanned" as "scanned, found nothing."

**The flat list is a primary view, not a fallback.** 45–52% of wild-light's active non-epic items have no epic parent (23 of 51 by index count; the higher 30-of-58 figure double-counts epics). At the largest measured scale roughly half the board is ungrouped — so the ticket's premise that the flat list is a small-N degradation is backwards, and the binding constraint is the *ungrouped fraction*, not item count. **Empty-epic sections are structurally guaranteed**, not merely untested. `build_epic_map` seeds `children_by_epic` with every epic id including zero-child ones (`build_epic_map.py:135-175`), so the moment a non-terminal epic's last active child completes, the board renders an empty section. **Correction to #411's spec:** it cites `game` as an observed out-of-vocab type. No frontmatter carries it — the only hit is inside a fenced code block in body prose (`wild-light/.../030-*.md:45`, whose own type is `feature`). A parser-scope error worth not repeating.

**Convention drift does exist at n=4**, contra #411's "no convention diversity": `superseded-by` (gaggimate-barista, 3×) vs `superseded_by` (cortex-command, 1×) — same author, same intent, different spelling. Every repo has also invented at least one unique one-off key (`abandoned_reason`, `spec_source`, `closed-reason`, …). None breaks parsing — `_parse_frontmatter` is tolerant by construction — but any closed-key-set assumption would flag false positives in every repo. Core schema fields (status, priority, type, tags, dates, `blocked-by`) do hold steady, and list style is 100% inline-bracket across all corpora, so the block-style-YAML edge case remains theoretical.

**Strip semantics differ by repo in kind, not just scale.** gaggimate-barista's `0 archived` means *the archive directory has never been created* — a workflow-adoption fact — and is indistinguishable from "archiving is on, nothing archived yet" if both render as `0`. wild-light's `88` reflects sustained archiver use and genuine re-accumulation. **Orphan lifecycle dirs run 50–65% in every repo** (dirs with no resolvable backlog cross-reference), so any "unswept" definition requiring a backlog join undercounts everywhere, not just in degenerate repos. **Floor:** existence, not size, is the gate — hall-dental (no `cortex/lifecycle/`) is the only clear self-hide case; Team-Builder-Bot at n=2 renders a true and useful line.

## Adversarial Review

- **The strip's headline number is not actionable in a consumer repo.** The `lifecycle-archive` recipe lives in *this* repo's `justfile` with a repo-relative glob, and `cortex-jcc` runs recipes in this repo's context. A wild-light operator reading "170 completed-but-unswept" has no command available to act on it. Siting the scan outside the backend gate is right for *reading*, but the third term names a remediation only cortex-command can perform. This is a framing obligation on the strip's wording, not a bug.
- **Unvendored CDN dependencies.** `base.html:11-13` loads htmx 2.0.4, idiomorph-ext 2.0.1, and `cdn.tailwindcss.com` from public CDNs; `find cortex_command/dashboard -name "*.js"` returns nothing. With unpkg unreachable, `hx-swap="morph"` names an unregistered extension and the sessionStorage restore carries `<details>` state alone. `cdn.tailwindcss.com` is the JIT browser build, so the `@theme` block compiles client-side at runtime. Pre-existing and out of scope, but every morph-preservation claim is conditional on it.
- **The `lru_cache` argument is real but an order of magnitude smaller than stated.** `common.py:242`'s `maxsize=128` is confirmed and two repos exceed it on raw dir count — but the only dashboard caller is `data.py:314`, iterating `overnight-state.json`'s features (~5–20 entries).
