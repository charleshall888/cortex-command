# Plan: reconcile-dashboard-docs-and-observability-requirements

## Overview

Collapse seven prose copies of the dashboard bind fact to two, flip the one non-loopback launch path (`just dashboard`) to a loopback default with an explicit `DASHBOARD_HOST` opt-in, then declare a dashboard-docs owner in `docs/policies.md` and route work to it from `CLAUDE.md`. Every edit is prose or `justfile` configuration — no Python behavior changes. The task graph is **one task per file per spec phase**: the six files touched only once become fully parallel level-1 tasks, and the three files touched by both phases (`cortex/requirements/observability.md`, `docs/dashboard.md`, `docs/overnight-operations.md`) split into a Phase-1 task and a Phase-2 task joined by an annotated write-serialization edge, because no registration seam exists for prose rework in a shared document. A final cross-file acceptance sweep verifies the two repo-wide requirements (R3, R11) that no single-file task can prove.

No recovery history exists for this feature (`learnings/recovery-log.md` absent), so no previously-failed approach constrains this plan.

- **Files**: `justfile`
- **What**: Replace the hardcoded `--host 0.0.0.0` and the `0.0.0.0` URL echo in the `dashboard` recipe with just-level variables that default to loopback, render `localhost` for display, and accept an explicit opt-in. Satisfies R1, R2, and the `justfile` half of R3.
- **Depends on**: none
- **Complexity**: simple
- **Context**: The recipe lives at `justfile:103-116` under the `# --- Dashboard ---` comment, with the existing `dashboard_port := env_var_or_default("DASHBOARD_PORT", "8080")` idiom at `justfile:101` directly above it. The display variable must be **top-level**, not a recipe-body shell conditional: `just --dry-run` expands only just-level interpolations, so a `$DISPLAY_HOST` in the body stays unexpanded and R2's checks fail on an otherwise-correct implementation. The recipe body also needs restructuring: today it echoes the URL in *two* places (the already-running early-exit branch at `justfile:111` and the launch line at `:115`), and R2 requires exactly **one** line matching `http://localhost:` in the dry-run output. This exact shape (three variables + hoisted echo) was executed against `just 1.55.1` in a scratch justfile and every check below returned the stated value. Do **not** write `just host=…` or `just dashboard host=…` anywhere — `just 1.55.1` rejects the first (`variable 'host' overridden on the command line but not present in justfile`) and passes the second as a positional string; the working operator forms are `DASHBOARD_HOST=0.0.0.0 just dashboard` and `just dashboard_host=0.0.0.0 dashboard`.
